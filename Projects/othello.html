Othello AI

An intelligent game-playing bot implementing minimax search, alpha-beta pruning, iterative deepening, and advanced move ordering heuristics to compete in high-performance tournaments.

Python Algorithms Minimax Alpha-Beta Pruning Game Theory

Overview

Othello (Reversi) is an 8x8 grid-based board game. Players take turns placing discs of their color. If an opponent's discs are sandwiched between the newly placed disc and another of the active player's discs in any straight line (horizontal, vertical, or diagonal), those discs are flipped. The game ends when neither player has legal moves, and the player with the most discs wins.

I built this zero-dependency Othello AI to compete under tight execution limits (typically 1.5 seconds per move). The engine constructs a virtual game tree of possible future board configurations, evaluates their strategic values, and makes optimal moves against an active opponent using game-theoretic search algorithms.

Core Architecture

  • Minimax with Alpha-Beta Pruning (Branch & Bound): Computes optimal decisions by maximizing the player's advantage while assuming the opponent acts to minimize it. Alpha-beta pruning cuts off branches that cannot affect the final decision, preventing redundant work.
  • Iterative Deepening: Rather than searching to a fixed depth, the bot searches depth-by-depth (depth 1, then depth 2, etc.). This ensures a valid move is always ready, regardless of the remaining time.
  • Exception-Based Time Management: Uses a high-precision timer. If the turn limit is reached, a custom SearchTimeout is raised, aborting the active search level and falling back to the completed move from the previous depth.

Search & Branching Optimizations

⚡ Move Ordering (Pruning Booster)

Alpha-beta pruning efficiency is highly dependent on move evaluation order. By sorting legal moves based on static board weights before entering search, the bot checks the most promising branches first. This leads to immediate cutoffs, reducing the search space from O(bd) towards the theoretical limit of O(bd/2).

♟️ Multi-Factor Heuristic Matrix

Uses a custom heuristic weighting matrix to evaluate board squares. Corners (which can never be flipped) are heavily prioritized (+100). Conversely, squares adjacent to empty corners (C & X squares) are penalized (-20 to -40) because they grant the opponent corner access.

🎛️ Dynamic Mobility & Parity

Early game success is about limiting opponent choices (mobility) rather than acquiring pieces. The bot calculates mobility dynamically to restrict opponent moves. During the endgame (last 10 empty squares), it scales up the parity weight from 1 to 5 to prioritize outright coin count for victory.

Search Implementation

client.py (Minimax Implementation) 
def minimax(self, state: GameState, depth: int, alpha: float, beta: float, maximizing: bool, player: int, initial_player: int) -> float:
    if time.time() > self.end_time:
        raise SearchTimeout()

    self.nodes_evaluated += 1
    opponent = 2 if player == 1 else 1
    moves = self.get_valid_moves_sorted(state, player)  # Optimizes Alpha-Beta via Move Ordering

    if depth == 0:
        return self.evaluate_board(state, initial_player)

    if not moves:
        opponent_moves = state.get_valid_moves(opponent)
        if not opponent_moves:
            return self.evaluate_board(state, initial_player)
        return self.minimax(state, depth - 1, alpha, beta, not maximizing, opponent, initial_player)

    if maximizing:
        max_eval = float('-inf')
        for move in moves:
            new_state = state.make_move(move, player)
            eval_score = self.minimax(new_state, depth - 1, alpha, beta, False, opponent, initial_player)
            max_eval = max(max_eval, eval_score)
            alpha = max(alpha, eval_score)
            if beta <= alpha:
                break  # Branch and bound pruning
        return max_eval
    else:
        min_eval = float('inf')
        for move in moves:
            new_state = state.make_move(move, player)
            eval_score = self.minimax(new_state, depth - 1, alpha, beta, True, opponent, initial_player)
            min_eval = min(min_eval, eval_score)
            beta = min(beta, eval_score)
            if beta <= alpha:
                break  # Branch and bound pruning
        return min_eval
